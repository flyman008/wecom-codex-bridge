# 安装配置项

仓库只提供能力和安全边界，不携带仓库作者的个人偏好。首次安装运行：

```bash
npm run setup
```

## 必须由安装人决定

| 决策 | 可选方式 | 保存位置 |
| --- | --- | --- |
| 消息路由 | 全部进入 Codex / 兼容模型语义路由 | `.env` |
| 机器人人设 | 专业简洁 / 温和简洁 / 完全自定义 | `.runtime/router-agent.profile.json` |
| 偏题提醒 | 关闭 / 自定义次数和文案 | 人设文件 |
| Codex 模型 | 指定首选与备用 / 留空继承 Codex | `.env` |
| 推理与速度 | 指定强度和 Fast / 留空继承 Codex | `.env` |
| 文件权限 | 只读 / 授权目录可写 | `.env` |
| 会话上下文 | 持久会话 / 每次独立 | `.env` |
| 登录后自启动 | 开启 / 关闭 | `.env` 与操作系统用户启动项 |

选择语义路由时，安装人还需要配置允许接入自建应用的 OpenAI 兼容模型；选择本地 Agent 时再配置其 URL 和可选 Token。

## 可继承 Codex 的项目

`CODEX_MODEL`、`CODEX_REASONING_EFFORT` 和 `CODEX_SERVICE_TIER` 留空时，桥接服务不会覆盖安装人当前的 Codex 配置。备用模型留空时不自动降级。

模型是否可用、支持哪些推理强度或速度档位，取决于安装人的 Codex 版本、账号和组织策略。配置向导不猜测账号权限。

## 重新配置

再次运行 `npm run setup` 会以现有本机配置为起点。Secret 和 Token 留空时保留原值；其他项目可以重新选择。

修改自启动选择后执行：

```bash
npm run autostart:apply
```

`false` 会移除当前仓库实例对应的用户级自启动项，但不会停止已手动启动的服务。启动项名称包含仓库路径哈希，因此不会误删同一台机器上的其他部署实例。
